# Шаблон Word-отчёта (паспорт расчёта ESG-рейтинга)

Работает для одногодичной и динамической оценки.

## Структура документа

**Титульный блок:** «Паспорт расчёта ESG-рейтинга — [Компания] — [Год(ы)]», методология v3, дата, итоговый балл + рейтинг (крупно).

**1. Объект оценки** — компания, период, периметр, максимум шкалы.

**2. Резюме результатов**

| Блок | Вес | Набрано | % |
|---|---|---|---|
| E — Экология | 333 | X,X | XX% |
| S — Социальная ответственность | 333 | X,X | XX% |
| G — Корпоративное управление | 333 | X,X | XX% |
| ИТОГО | 999 | X,X | XX% |

**2.1. Индикаторы качества анализа:** страниц PDF; страниц с текстом / без текста; OCR-предупреждения; извлечено числовых значений; токенов потрачено; загрузка контекста %; 🟢/🟡/🔴 запас.

**2.2. Покрытие показателей:** x>0 — X из N (XX%); доля со ссылкой на PDF — X из N; 🟢/🟡/🔴 оценка; список высоковесных показателей с x=0.

**2.3. Лучшие практики (top-5)** — с PDF-ссылками.

**2.4. Проблемные зоны (top-5)** — низкий x при высоком весе, отметки о жёстких потолках, PDF-ссылки.

**2.5. Потенциал роста** — для нулевых показателей: примеры лучших практик (Newmont, Barrick, Agnico Eagle).

**3. Санкционный корректив** (если применён) — таблица: x_raw / бонус / x_final / ограничитель / основание.

**4. Матрица отраслевых рисков** — 10 рисков × 4 контура (Документ/ВНД/Меры/КПЭ), цветовая индикация.

**5–7. Декомпозиция по блокам E, S, G** — сводная таблица с PDF-ссылками + детальный разбор каждого показателя (x, балл, цитата, обоснование, потолки, бонус).

**8. Динамический анализ** (если лет > 1) — ΔScore, CAGR, декомпозиция, топ-5 драйверов роста/снижения.

**8а. АКРА-профиль финансовой прозрачности** — отдельная мини-таблица по G12:

| Суб-компонент | Факт раскрытия | Источник | Вклад в x |
|---|---|---|---|
| a. Отчётность МСФО (квартальная / годовая / нет) | ... | ... | 0–0,55 |
| b. Аудит + открытый публичный доступ | ... | ... | 0–0,20 |
| c. Операционные данные + IR-материалы | ... | ... | 0–0,15 |
| d. Структура группы + бенефициар | ... | ... | 0–0,10 |
| **Итого G12** | **Уровень АКРА: [Очень высокий / Высокий / Средний / Очень низкий]** | | **x = ...** |

Пояснение: указать, какой именно уровень по шкале АКРА зафиксирован и что является ограничивающим фактором (при x < 1,0).

**9. Ограничения**

**10. Заключение**

**Приложение:** сводная таблица 32 показателей — Код / Показатель / Вес / x / Балл / Источник в PDF.

## Правила оформления

- Times New Roman 12, интервал 1,5
- Поля: 2,5 / 3 / 1,5 / 2,5 см
- Таблицы: заголовок D5E8F0 (светло-голубой)
- Матрица рисков: зелёный C8E6C9 / розовый FFCDD2
- Все количественные значения с PDF-ссылкой
