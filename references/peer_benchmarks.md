# Справочник Peer-Set и Absolute Thresholds

## Как использовать

1. Для российской компании → применять **Russian peer-set**.
2. Для международной компании → применять **Global peer-set**.
3. Если в peer-set <5 сопоставимых компаний за данный год → переключиться на **Absolute Thresholds** (ICMM benchmark), зафиксировать переход в паспорте расчёта.
4. Peer-set **фиксируется на тот же отчётный год**, за который считается рейтинг.

## Правила применения

1. **При использовании peer-set**: ранжировать компанию среди 5+ peer'ов. Вычислить процентиль:
   - Для минимайзера: `x = 1 − percentile_rank(value, peer_values)` (compressed; компания с наименьшим значением получает x=1).
   - Для максимайзера: `x = percentile_rank(value, peer_values)`.
2. **При fallback на absolute thresholds**: брать x напрямую из таблицы для ближайшего порога; зафиксировать в паспорте «применены absolute thresholds».
3. **Смешанный режим запрещён**: либо peer-set, либо absolute thresholds — для одного показателя. Для разных показателей может быть разный режим (например, E1 — peer-set, S4 — thresholds из-за неполноты раскрытия).

## Обновление справочника

Этот справочник — snapshot за 2024 год. При оценке за 2023 или 2025 годы пользователь должен:
- Верифицировать значения peer'ов по их отчётам соответствующего года (значения меняются ежегодно).
- Зафиксировать использованный snapshot в паспорте расчёта (п. 7.11).
- При отсутствии свежих данных — использовать absolute thresholds (они меняются реже, раз в 3–5 лет с обновлением ICMM benchmark).
