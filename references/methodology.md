## БЛОК E — Экология (333 балла)

### E1. Удельные выбросы ПГ (Scope 1+2). Вес: 54
- Тип: минимайзер. `x = 1 − percentile(тCO₂e/oz AuEq)`. Балл = `54 × x`.
- Понижения: только охват 1 или только абсолют без удельного → `x ≤ 0,6`; границы консолидации не описаны → `x × 0,9`; не раскрыто → `x = 0`.

### E2. Полнота охвата 3. Вес: 18
- Существенные категории для золотодобычи: 1, 4, 11.
- `x = раскрытые_существенные_категории / 3`. Балл = `18 × x`. Не раскрыто → `x = 0`.

### E3. Энергоинтенсивность. Вес: 30
- Тип: минимайзер. `x = 1 − percentile(кВт·ч или ГДж/oz AuEq)`. Балл = `30 × x`.
- Понижение: структура энергобаланса (топливо/электро/тепло) не раскрыта → `x ≤ 0,7`.

### E4. Доля ВИЭ в электропотреблении. Вес: 25
- Тип: максимайзер. `x = доля_ВИЭ`. Балл = `25 × x`.
- Понижение: только сертификаты происхождения без PPA/генерации → `x ≤ 0,8`.

### E5. Удельное водопотребление и водный стресс. Вес: 30
- `x = (1 − percentile(м³/oz)) × (1 − доля_в_зонах_стресса × 0,3)`. Балл = `30 × x`.
- Бонус: раскрытие замкнутого водооборота → `+0,05` (но x ≤ 1).
- При невозможности определить зоны стресса: доля = 0.

### E6. Управление хвостохранилищами (GISTM). Вес: 60
Шкала 0–4: 0 — нет упоминаний TSF; 1 — перечень раскрыт; 2 — классификация по consequence class + независимые инспекции; 3 — соответствие GISTM + Accountable Executive + Engineer of Record; 4 — внешнее подтверждение соответствия + данные мониторинга.
`x = уровень / 4`. Балл = `60 × x`.
TSF-инцидент в отчёте → уровень автоматически ≤ 2 + отражается в E10.

### E7. Опасные вещества (цианиды, ртуть). Вес: 35
Шкала 0–4: 0 — нет; 1 — политика; 2 — аудит операций; 3 — соответствие ICMI Cyanide Code; 4 — сертификация ICMI по всем площадкам + отказ от ртути.
`x = уровень / 4`. Балл = `35 × x`.
N/A: нет heap leach / CIL → вес перераспределяется (см. «Применимость»).

### E8. Биоразнообразие. Вес: 30
Шкала 0–4: 0 — нет; 1 — декларация; 2 — инвентаризация; 3 — BAP с KPI, no-net-loss; 4 — net-positive + offsets.
`x = (уровень/4) × 0,7 + (1 − доля_в_охраняемых_зонах) × 0,3`. Балл = `30 × x`.

### E9. Рекультивация и ARO. Вес: 25
Шкала 0–4: 0 — нет; 1 — декларация; 2 — план закрытия описан; 3 — ARO по МСФО раскрыты количественно, актуализируются ежегодно; 4 — покрытие гарантиями/трастами + прогрессивная рекультивация.
`x = уровень / 4`. Балл = `25 × x`.

### E10. Экологические штрафы и инциденты. Вес: 16
- Тип: минимайзер. `x = 1 − percentile(удельные_штрафы)`. Балл = `16 × x`.
- Крупный инцидент (разлив хвостов, превышение ПДК с санкциями) → дополнительно `x × 0,5`.

### E11. ISO 14001. Вес: 10
- Охват ≥ 80% → `x = 1`; 50–80% → `x = 0,5`; <50% или нет → `x = 0`. Балл = `10 × x`.

**Сумма E: 54+18+30+25+30+60+35+30+25+16+10 = 333 ✓**

## БЛОК S — Социальная ответственность (333 балла)

### S1. LTIFR. Вес: 55
- Тип: минимайзер. `x = 1 − percentile`. Балл = `55 × x`.
- Понижения: база часов не раскрыта → `x ≤ 0,6`; только сотрудники без подрядчиков → `x ≤ 0,8`.

### S2. Fatalities. Вес: 60
- Тип: минимайзер. `x = 1 − percentile`. Балл = `60 × x`.
- **🔴 ЖЁСТКИЙ ПОТОЛОК: fatalities > 0 → x ≤ 0,5** (отраслевой консенсус «zero harm», ICMM).

### S3. ISO 45001. Вес: 18
- Охват ≥ 80% → `x = 1`; поэтапное внедрение → `x = 0,5`; иначе → `x = 0`.
- Бонус: дополнительные сертификации → `+0,05`. Балл = `18 × x`.

### S4. Профессиональные заболевания. Вес: 30
- Тип: минимайзер. `x = 1 − percentile(случаи/1000 работников)`. Балл = `30 × x`.
- Понижение: методика учёта не раскрыта → `x ≤ 0,6`.

### S5. Текучесть персонала. Вес: 20
- Тип: минимайзер. `x = 1 − percentile(выбывшие/среднесписочная)`. Балл = `20 × x`.

### S6. Обучение персонала. Вес: 15
- Тип: максимайзер. `x = percentile(часы/работника)`. Балл = `15 × x`.
- Бонус: специализированные программы для опасных условий → `+0,05`.

### S7. Права коренных народов и сообществ. Вес: 55
Шкала 0–4: 0 — нет политики; 1 — декларация о правах человека; 2 — FPIC описана и применяется; 3 — IBA-соглашения по всем применимым проектам, суммы раскрыты; 4 — независимый мониторинг, grievance mechanism по UNGP.
`x = уровень / 4`. Балл = `55 × x`.
**🔴 ЖЁСТКИЙ ПОТОЛОК: действующий конфликт/иск с сообществом → x ≤ 0,5.**
N/A: нет операций в регионах коренных народов → вес перераспределяется. Для российских компаний — всегда применим (КМНС присутствуют во всех регионах крупных золотодобытчиков).

### S8. Due diligence поставщиков. Вес: 20
- `x = доля критических поставщиков с ESG-проверкой`. Балл = `20 × x`.
- Понижение: критерии критичности не раскрыты → `x ≤ 0,7`.
- Бонус: соответствие OECD Due Diligence for Minerals.

### S9. Механизм обращений работников. Вес: 15
- `x = доля_урегулированных`. Балл = `15 × x`.
- <5 обращений за год → использовать среднее за 3 года (при наличии).

### S10. Социальные инвестиции. Вес: 45
- Тип: максимайзер. `x = percentile(min(факт, предел_отрасли))`, где факт = (соц. программы + инвестиции в сообщества) / выручка. Балл = `45 × x`.
- Только добровольные/стратегические программы.

**Сумма S: 55+60+18+30+20+15+55+20+15+45 = 333 ✓**

## БЛОК G — Корпоративное управление (333 балла)

### G1. Доля независимых директоров. Вес: 33
- `x = percentile` ИЛИ: ≥50% → x=1,0; 33–50% → x=0,7; <33% → x=0,4. Балл = `33 × x`.
- Понижение: критерии независимости не раскрыты → `x ≤ 0,5`.
- **АКРА-сигнал:** публичное раскрытие состава СД (число, имена, статус независимости) — обязательное условие x > 0,5.

### G2. Разделение председателя СД и CEO. Вес: 12
- Разделены >90% периода → `x = 1`; совмещение → `x = 0`. Балл = `12 × x`.

### G3. Антикоррупционная система. Вес: 22
- ISO 37001 или эквивалент (политика + обучение + проверки + канал + расследования) → `x = 1`; частичное → `x = 0,5`; иначе → `x = 0`. Балл = `22 × x`.

### G4. Подтверждённые случаи коррупции. Вес: 40
- Тип: минимайзер. `x = 1 − percentile`. Балл = `40 × x`.
- **🔴 ЖЁСТКИЙ ПОТОЛОК: подтверждённые случаи > 0 → x ≤ 0,5.**

### G5. Надзор СД за ESG + вознаграждение. Вес: 40
Шкала 0–4: 0 — нет надзора; 1 — ESG в повестке; 2 — комитет + ≥2 рассмотрения/год; 3 — ESG-KPI в системе вознаграждения; 4 — измеримые ESG-KPI с весами и порядком.
`x = уровень / 4`. Балл = `40 × x`.

### G6. Управление рисками и внутренний контроль. Вес: 30
Шкала 0–4: 0 — фрагментарный; 1 — общие политики; 2 — реестр рисков; 3 — регулярная оценка + тестирование контролей; 4 — интеграция в стратегию + отчётность СД + количественный риск-аппетит с climate- и TSF-рисками.
`x = уровень / 4`. Балл = `30 × x`.

### G7. Whistleblower-канал. Вес: 25
- `x = 0,5 × наличие + 0,5 × доля_урегулированных`. Балл = `25 × x`.
- Канал есть, но нет статистики → вторая часть = 0.

### G8. Стандарты ответственной золотодобычи. Вес: 45
Шкала 0–4: 0 — нет соответствия; 1 — декларация о намерении; 2 — LBMA RGG report публикуется; 3 — полное соответствие WGC RGMP + независимый аудит; 4 — сертификация RJC CoC + членство ICMM + публичный прогресс WGC RGMP.
`x = уровень / 4`. Балл = `45 × x`.

### G9. Раскрытие запасов и ресурсов. Вес: 30
Шкала 0–4: 0 — только ГКЗ без пояснений; 1 — ГКЗ + декларация соответствия; 2 — JORC/NI 43-101/CRIRSCO для ключевых активов; 3 — полное раскрытие для всех активов с Competent Person; 4 — ежегодное обновление + сценарные расчёты + Mineral Reserve Statement с assurance.
`x = уровень / 4`. Балл = `30 × x`.

### G10. Налоговая прозрачность и EITI. Вес: 25
Шкала 0–4: 0 — нет; 1 — общие положения; 2 — налоговая политика раскрыта; 3 — country-by-country reporting + платежи властям; 4 — EITI или GRI 207 с assurance.
`x = уровень / 4`. Балл = `25 × x`.

### G11. Качество раскрытия ESG (мета-показатель). Вес: 22
Шкала 0–4: 0 — нет регулярного раскрытия; 1 — фрагментарное; 2 — регулярный отчёт с пробелами; 3 — структурирован по существенности + сопоставимые показатели + связь с управлением; 4 — сопоставимость + связь с финансами + методики + внешнее assurance (≥ limited).
`x = уровень / 4`. Балл = `22 × x`.

### G12. Финансовая прозрачность (АКРА-методология). Вес: 9

> **Новый показатель v4.** Интегрирует субфактор «Финансовая прозрачность» методологии АКРА для нефинансовых компаний в части публичного раскрытия в открытом доступе.

Комбинированная формула из 4 суб-компонентов (сумма = x):

| Суб-компонент | Условие | Вклад в x |
|---|---|---|
| **a. Отчётность МСФО** | Только РСБУ / нет МСФО → 0; МСФО есть, годовая, публично → 0,40; + квартальная МСФО → +0,15 | 0–0,55 |
| **b. Аудит и доступ** | Аудиторское заключение + открытый доступ на сайте (не только аналитикам) → 0,20; только закрытое предоставление → 0,10; нет → 0 | 0–0,20 |
| **c. Операционные данные и IR-материалы** | Регулярные IR-презентации + операционные KPI публично → 0,15; только IR-презентации или только KPI → 0,08; нет → 0 | 0–0,15 |
| **d. Структура группы и собственность** | Конечный бенефициар и цепочка владения раскрыты публично, структура прозрачна → 0,10; частично → 0,05; нет → 0 | 0–0,10 |

`x = a + b + c + d` (но ≤ 1,0). Балл = `9 × x`.

**Шкала АКРА → x:**
- Очень высокий (квартальная МСФО + операционные данные + IR + прозрачная структура) → x ≈ 1,0
- Высокий (годовая МСФО + аудит + прозрачная структура) → x ≈ 0,70
- Средний (МСФО с задержками или без полной консолидации) → x ≈ 0,40
- Очень низкий (только РСБУ) → x = 0

**Жёсткий потолок:** если МСФО отсутствует (только РСБУ) → `x = 0` независимо от других суб-компонентов (АКРА: «потолок заблокирован»).

**Примечание:** для российских компаний под санкциями — раскрытие по МСФО на российских площадках (Мосбиржа, сайт компании) засчитывается полностью; требование западного аудитора **не** применяется.

**Сумма G: 33+12+22+40+40+30+25+45+30+25+22+9 = 333 ✓**

## Санкционная компонента

Если компания не может получить формальное соответствие международным стандартам из-за санкций (OFAC/EU/UK делистинг, приостановка членства в ICMM/WGC/LBMA/RJC, невозможность выпуска JORC с западными QP, приостановка EITI) — применяется **бонус +0,20 к x** по показателям G8, G9, G10.

**Условия:** компания раскрывает санкционный факт OR он общеизвестен (санкционный список OFAC/EU/UK). Бонус только к G8/G9/G10.

**Формула:** `x_final = min(x_raw + 0,20; x_raw × 2; 1,0)`
- `x_raw × 2` — ограничитель anti-washing: при x_raw = 0 бонус = 0 (компания ничего не делает по стандарту). При x_raw ≥ 0,25 бонус применяется полностью.

**В паспорте указать:** факт ограничения + источник; показатели с бонусом; x_raw и x_final; сработавший ограничитель.

## Приложение: Методология АКРА — требования к раскрытию (v4)

Интегрировано в G12. Источник: методология АКРА для нефинансовых компаний, субфактор «Финансовая прозрачность».

### Шкала АКРА (4 уровня)

| Уровень | Что раскрыто публично | Соответствие x G12 |
|---|---|---|
| **Очень высокий** | Квартальная консолидированная МСФО + аудит + операционные данные + IR-презентации + прозрачная структура владения | x ≈ 1,0 |
| **Высокий** | Годовая консолидированная МСФО в открытом доступе + аудит + прозрачная структура группы | x ≈ 0,70 |
| **Низкий / средний** | МСФО есть, но с задержками / неполная консолидация / нет открытого доступа | x ≈ 0,40 |
| **Очень низкий** | Только РСБУ, МСФО отсутствует | x = 0 |

### Ключевые требования АКРА

1. **МСФО — базовое условие:** отсутствие консолидированной МСФО (только РСБУ) → x = 0, потолок заблокирован.
2. **Открытый доступ:** публикация на сайте компании в открытом доступе, а не только закрытое предоставление аналитикам.
3. **Периодичность:** годовая → высокий уровень; ежеквартальная → очень высокий.
4. **Дополнительные IR-материалы:** операционные результаты (KPI), инвесторские презентации, звонки — позитивный сигнал к очень высокому уровню.
5. **Структура группы:** понятная цепочка владения и конечный бенефициар раскрыты публично.
6. **СД:** публичное раскрытие состава, числа и статуса независимых директоров (учитывается в G1, не дублируется в G12).

### Взаимодействие G12 с другими показателями

- G12 оценивает **финансовую прозрачность** (МСФО, IR, структура). G11 оценивает **ESG-раскрытие** (GRI, TCFD, assurance). Перекрытия нет.
- G1 учитывает публичное раскрытие состава СД как понижающий коэффициент — G12 его не дублирует.
- Санкционный бонус (G8/G9/G10) на G12 **не распространяется**: АКРА-прозрачность возможна на российских площадках без западных стандартов.
