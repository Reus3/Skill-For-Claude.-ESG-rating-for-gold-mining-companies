# Гайд по извлечению данных из годового отчёта

Где искать каждый из 32 показателей. Шкалы уровней зрелости и формулы — в `methodology.md`.

## Общие правила

1. **Источники по приоритету:**
   - Отчёт об устойчивом развитии / ESG report — главный.
   - ESG databook / Performance tables — количественные данные.
   - Годовой отчёт (annual report) — финансовые данные, состав СД, ARO.
   - Mineral Resources and Reserves Statement — для G9.
   - LBMA RGG report / GISTM Disclosure — для G8 / E6.

2. **PDF-ссылки для каждого раскрытого показателя (x > 0):**
   - `source_page` — число (например, `46`).
   - `pdf_page_ref` — текст (например, `"стр. 46, раздел «Окружающая среда»"`).
   - `raw_quote` — точная цитата (1 предложение).

3. **Санкционный флаг** для российских компаний по G8/G9/G10:
   ```json
   "sanctions_barrier": true,
   "sanctions_reason": "Делистинг с LSE, приостановка членства в ICMM/WGC/LBMA"
   ```

4. **Поиск на русском и английском одновременно** — российские компании публикуют билингвальные отчёты.

## E — Экологические показатели

### E1. Удельные выбросы Scope 1+2
**Разделы:** «Климат», «Изменение климата», «Углеродный след»; Climate, Emissions, Carbon Footprint; ESG databook → GHG emissions.
**Фразы RU:** «выбросы парниковых газов», «охват 1», «охват 2», «тCO₂-эквивалент», «тCO₂е».
**Фразы EN:** "Scope 1 emissions", "Scope 2 emissions", "GHG emissions", "tCO2e".
**Извлечь:** Scope 1 (тCO₂e) + Scope 2 (тCO₂e) + производство AuEq → рассчитать удельный (или взять напрямую если раскрыт). Описание границ консолидации.

### E2. Охват 3
**Фразы:** «охват 3», "Scope 3", «категория 1/4/11», "upstream transportation", "purchased goods".
**Извлечь:** перечень раскрытых категорий. Приоритет: кат. 1, 4, 11.

### E3. Энергоинтенсивность
**Разделы:** «Энергоэффективность», «Потребление энергии», «Энергобаланс»; Energy consumption.
**Извлечь:** общее потребление (ГДж/ТДж/кВт·ч) + производство AuEq; структура: топливо/электричество/тепло.

### E4. Доля ВИЭ
**Фразы:** «ВИЭ», «возобновляемые источники», «PPA», «зелёные сертификаты»; "renewable energy", "solar", "wind", "hydro".
**Извлечь:** доля ВИЭ от **электропотребления** (не от общей энергии).

### E5. Вода
**Разделы:** «Управление водными ресурсами»; Water management.
**Извлечь:** водозабор (м³), доля оборотной воды, расположение операций. Зоны стресса — WRI Aqueduct; при отсутствии данных: доля = 0.

### E6. Хвостохранилища (GISTM)
**Разделы:** «Хвостохранилища», отдельный GISTM Disclosure, Tailings Management.
**Фразы:** «GISTM», «TSF», «хвостохранилище», «Accountable Executive», «Engineer of Record», «consequence class».
**Определение уровня:** по шкале 0–4 из methodology.md. Пример: Полюс (стр. 241-242) — классификация 4.1 GISTM, ежегодные оценки рисков, независимые обследования → уровень ~3.

### E7. Опасные вещества (цианиды, ртуть)
**Фразы:** «цианид», «ICMI», "International Cyanide Management Code", «ртуть», "cyanide".
**Определение уровня:** шкала 0–4 из methodology.md.

### E8. Биоразнообразие
**Разделы:** «Биоразнообразие», «Воздействие на территорию»; Biodiversity, Land use.
**Фразы:** «BAP», "Biodiversity Action Plan", "no-net-loss", "net positive impact", UNESCO, IUCN.

### E9. Рекультивация / ARO
**Источники:** финансовая отчётность (пояснения к резервам по МСФО); разделы «Рекультивация», «Закрытие рудников».
**Фразы:** «ARO», "asset retirement obligation", «обязательства по закрытию», "mine closure", "reclamation".

### E10. Экологические штрафы
**Разделы:** «Соблюдение экологического законодательства»; примечания к фин. отчётности (судебные риски).
**Фразы:** «штрафы», «предписания», «инциденты», «разливы»; "environmental fines", "penalties", "spills".

### E11. ISO 14001
**Разделы:** «Системы менеджмента»; приложения с сертификатами.
**Извлечь:** наличие сертификата + охват (% активов/деятельности).

## S — Социальные показатели

### S1. LTIFR
**Разделы:** «Охрана труда и промышленная безопасность»; ESG databook.
**Фразы:** «LTIFR», «коэффициент частоты травматизма», «на 200 000 часов», «на 1 000 000 часов»; "Lost Time Injury Frequency Rate", "TRIFR".
**Важно:** проверять базу (сотрудники vs сотрудники+подрядчики) и коэффициент (на 200 тыс. vs на 1 млн часов).

### S2. Fatalities
**Фразы:** «смертельные случаи», «fatal accident», «fatalities», FIFR.
**Извлечь:** абсолютное число за год (сотрудники + подрядчики). При > 0 → жёсткий потолок x ≤ 0,5.

### S4. Профзаболевания

### G12. Детальное руководство по извлечению (АКРА-прозрачность)

G12 оценивается по 4 суб-компонентам. Для каждого фиксируй `source` (URL сайта или раздел отчёта) и `raw_quote`.

**a. Отчётность МСФО:**
- Ищи в заглавных страницах отчёта, разделе «О компании / О группе», разделе «Финансовые результаты».
- Фразы RU: «консолидированная финансовая отчётность по МСФО», «МСФО (IFRS)», «аудированная отчётность», «ежеквартальная отчётность».
- Фразы EN: "IFRS consolidated financial statements", "quarterly financial results", "audited accounts".
- Проверь сайт компании (раздел «Инвесторам» / "Investor Relations") — есть ли опубликованная отчётность в открытом доступе.
- **Если отчёт не содержит упоминания МСФО → x = 0, фиксируй «только РСБУ/нет данных».**

**b. Аудит и публичный доступ:**
- Фразы: «аудиторское заключение», «аудитор», "independent auditor's report", «доступно на сайте», "available on the website".
- Различай: «предоставляется по запросу» (= не открытый доступ) vs «опубликовано на сайте» (= открытый доступ).

**c. Операционные данные и IR-материалы:**
- Ищи упоминания «презентации для инвесторов», «операционные результаты», «День инвестора», «звонок с аналитиками».
- Фразы: «производственные показатели», «KPI», «IR-презентация», "earnings call", "investor day", "operational results".

**d. Структура группы и собственность:**
- Разделы: «Структура группы», «Корпоративная структура», «Сведения об акционерах», «Бенефициарные владельцы».
- Фразы: «конечный бенефициарный владелец», «цепочка владения», «схема владения», "beneficial owner", "ownership structure", "group structure".
- Оценивай прозрачность схемы: понятны ли все звенья цепочки, нет ли офшорных SPV без раскрытия конечного владельца.

## Программное извлечение

```python
import fitz
doc = fitz.open(path)
full_text = "\n".join(page.get_text() for page in doc)

import re
# Пример: LTIFR
m = re.search(r'LTIFR.{0,200}?(\d+[,.]?\d*)', full_text)
```

Для DOCX: `extract-text` из skill `docx` или `python-docx`.

**Совет:** извлекай оглавление (первые 5–10 страниц) — оно покажет, на каких страницах искать каждый раздел.

## Техническая проверка чтения PDF

```python
import fitz

def technical_pdf_check(path, min_text_len=50):
    """Возвращает поля для meta.json: total_pdf_pages, pages_with_text,
    pages_without_text, ocr_warnings."""
    doc = fitz.open(path)
    total = len(doc)
    pages_with_text = 0
    blank_pages = []
    for i, page in enumerate(doc, start=1):
        text = page.get_text().strip()
        if len(text) >= min_text_len:
            pages_with_text += 1
        else:
            blank_pages.append(i)
    doc.close()

    ocr_warnings = []
    if blank_pages:
        ranges = []
        s = blank_pages[0]; prev = s
        for p in blank_pages[1:]:
            if p == prev + 1:
                prev = p
            else:
                ranges.append((s, prev)); s = p; prev = p
        ranges.append((s, prev))
        for s, e in ranges:
            page_str = f"стр. {s}" if s == e else f"стр. {s}-{e}"
            ocr_warnings.append(f"{page_str} — скан или графика без текстового слоя")

    return {
        "total_pdf_pages": total,
        "pages_with_text": pages_with_text,
        "pages_without_text": total - pages_with_text,
        "ocr_warnings": ocr_warnings,
    }
```

Если `pages_without_text > 0` — уведомить пользователя в основном ответе (не только в Word).
