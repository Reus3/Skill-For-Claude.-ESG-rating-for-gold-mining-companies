# ESG-рейтинг золотодобывающих компаний (disclosure-based, v4)

Skill реализует авторскую методологию: **33 показателя** (11 E + 10 S + **12 G**), 999 баллов (три блока по 333), шкала AAA–C. Шкала, формулы, потолки, санкционный бонус — в `references/methodology.md`.

**Что нового в v4:** интегрирована методология АКРА (субфактор «Финансовая прозрачность»). Добавлен показатель **G12 «Финансовая прозрачность (АКРА)»** (вес 9). Веса G1 (35→33) и G11 (29→22) скорректированы. G12 оценивает: наличие и периодичность МСФО, открытость доступа, IR-материалы, прозрачность структуры группы.

## Когда использовать

Пользователь прикладывает годовой отчёт золотодобывающей компании (PDF/DOCX) и просит ESG-оценку; сравнение нескольких лет; «применить методологию» / «сделать по моим критериям».

## Главное правило

**Методология disclosure-based.** Оцениваем ТОЛЬКО то, что раскрыто в отчёте. Не догадываемся, не дополняем из внешних источников. Если показатель не раскрыт — x=0, балл=0, причина фиксируется в паспорте.

## Алгоритм работы

### Шаг 1 — Загрузка методологии
Прочитай `references/methodology.md` — полная спецификация 32 показателей: формулы, веса, правила нормирования, жёсткие потолки, санкционный бонус. **Всегда сверяйся с этим файлом при расчёте каждого показателя — не держи методологию в памяти.**

### Шаг 2 — Техническая проверка PDF (обязательный)
До извлечения данных проверь количество страниц с текстовым слоем (сниппет — `references/extraction_guide.md`, раздел «Техническая проверка»). Сохрани в `meta.json`.

Если `pages_without_text > 0` — уведоми пользователя: «В PDF обнаружено N страниц без текстового слоя (вероятно, сканы, страницы X-Y). Часть данных может быть не учтена. Рекомендую OCR или дополнительный текстовый отчёт.»

### Шаг 3 — Извлечение данных
Читай отчёт из `/mnt/user-data/uploads/`. PDF — через `pdftotext` или PyMuPDF постранично. DOCX — через `extract-text`.

Следуй `references/extraction_guide.md` — где искать каждый из 32 показателей, ключевые фразы. Для каждого раскрытого значения фиксируй `source_page` и `pdf_page_ref` (например, `"стр. 36, раздел Охрана труда"`).

### Шаг 4 — Формирование peer-set
Загрузи `references/peer_benchmarks.md`. Для количественных показателей (E1, E3, E5, E10, S1, S2, S4, S5, S10):
- Российская компания → Russian peer-set; международная → Global peer-set.
- Если peer-set <5 компаний за данный год → absolute thresholds (фиксируй переключение в паспорте).

### Шаг 5 — Расчёт показателей
Для каждого из 33 показателей:
1. Извлеки значение (или зафиксируй «не раскрыто»).
2. Рассчитай x ∈ [0; 1] по правилу нормирования из methodology.md.
3. Примени понижающие коэффициенты при неполноте раскрытия.
4. Примени жёсткие потолки (S2, G4, S7 при триггерах; G12 при отсутствии МСФО → x=0).
5. Примени санкционный бонус G8/G9/G10, если `sanctions_barrier: true`. **Бонус на G12 не распространяется.**
6. Балл = вес × x.

**Используй `scripts/calculate_rating.py`** — принимает JSON с извлечёнными данными, выдаёт полную декомпозицию.

**Санкционная компонента:** если компания под санкциями (OFAC/EU/UK, делистинг, приостановка членства в ICMM/WGC/LBMA/RJC) — для G8, G9, G10 добавь `sanctions_barrier: true` и `sanctions_reason: "..."`. Правила и ограничитель `x × 2` — в methodology.md.

### Шаг 6 — Динамический анализ (если >1 года)
По п. 7.9 methodology.md: ΔScore, CAGR, декомпозиция по E/S/G, топ-5 вкладчиков в рост и снижение, разделение «реальное улучшение» vs «улучшение раскрытия».

### Шаг 7 — Формирование Word-отчёта
Перед запуском создай `meta.json`:
```json
{
  "total_pdf_pages": 52,
  "pages_with_text": 50,
  "pages_without_text": 2,
  "values_extracted": 18,
  "tokens_used": 85000,
  "context_budget": 200000,
  "ocr_warnings": ["стр. 23-24 — графическая вставка без текстового слоя"]
}
```

Запусти: `python scripts/build_docx_report.py result.json /mnt/user-data/outputs/ESG_<company>_<year>.docx --meta meta.json`

Структура отчёта — `references/report_template.md`. Файл презентуется через `present_files`.

## Что НЕ делать

- **Не делай controversies overlay** — негативные события учитываются только через жёсткие потолки S2/G4/S7 при раскрытии в отчёте.
- **Не фантазируй значения** — нет данных → «не раскрыто, x=0».
- **Не меняй веса** — зафиксированы в methodology.md.
- **Не смешивай peer-set разных лет.**
- **Не применяй к другим отраслям.**
